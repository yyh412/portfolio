# Yuehang Yuan — Portfolio Prototype

A first HTML/CSS/JavaScript prototype inspired by the visual references supplied by Yuehang.

## Preview locally
1. Extract the folder.
2. Open `index.html` in a modern browser. For the best experience, use VS Code with the Live Server extension.

## Files
- `index.html`: page structure
- `styles.css`: visual design and responsive layout
- `script.js`: morphing lime-particle animation and project preview dialogs
- `assets/portrait-grayscale.jpg`: grayscale version of the supplied portrait

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with the preferred contact email.
- Replace the CSS-built placeholder project previews with screenshots from actual projects.
- Update the project descriptions and add proper case-study pages.
- Add your CV link when ready.

## Publish with GitHub Pages
Create a public repository named `YOUR-USERNAME.github.io`, upload all files while preserving the `assets` folder, then go to Settings → Pages → Deploy from a branch → `main` → `/(root)`.
